# portfolio-website
Developer portfolio showcasing web projects, UI/UX designs, and technical skills.
I focused heavily on the visuals and fixed clutter across different viewports. I swapped out my original font for an Inter system-ui stack to keep text clear. I switched my color palette to a dark background with a high contrast color to grab the attention toward my project links. 

One thing I noticed was the grid getting cramped on mid-sized tablet screens around 768px—the spacing feels a bit tight before the media query kicks down to a single-column layout. I left it functional for now, but tightening up those intermediate breakpoint margins and refining the touch-target spacing for mobile nav buttons are the main things I’d revisit next.
