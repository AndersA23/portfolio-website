# portfolio-website
Developer portfolio showcasing web projects, UI/UX designs, and technical skills.
For this update, I transitioned my previous homepage into a better portfolio layout using a dark theme with CSS. I went with Inter and adjusted the line-height to keep the project descriptions readable, then used a blue accent on the navigation and cards to establish clarity. I tested the responsiveness using browser DevTools against mobile breakpoints. The layout looks good but the header links feel slightly cramped on narrow screens. I also staged variables for an alternate light mode theme, which I plan to hook up with a JavaScript toggle in the future.
